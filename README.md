# TechArtCourse (Obsidian Vault)

Personal Tech Art / Unity engineering notes in an Obsidian vault format.

## How to use

- Clone the repo
- Open the folder as a vault in Obsidian: **Open folder as vault**
- Start at `Home.md`

## Contents

- `Home.md`: entry point
- `MOC Unity.md`: Unity map of content
- `MOC Foundations.md`: SOLID / architecture map of content
