# Learning Path

If you feel your knowledge is “scattered”, follow this order. Each step is designed to unlock the next.

> [!tip] How to use
> Read **Core** first. Only move to **Recommended** when you can explain the core ideas in your own words.

## Phase 0 — Setup (10 minutes)
- Open `Home.md`
- Use **Ctrl+O** to jump between notes
- Keep one note per concept, link aggressively

## Phase 1 — Core foundations (highest priority)
1. [[SRP (Single Responsibility Principle)]]
2. [[ISP (Interface Segregation Principle)]]
3. [[DIP (Dependency Inversion Principle)]]
4. [[Dependency Injection]]
5. [[Event-Driven Architecture]]

## Phase 2 — Core Unity engineering (highest ROI)
1. [[Unity Lifecycle (Awake vs Start)]]
2. [[Caching in Unity]]
3. [[Avoid Update Tax]]
4. [[ScriptableObjects for Data]]
5. [[UniTask Notes]]

## Phase 3 — Recommended next (after Core)
- [[OCP (Open-Closed Principle)]]
- [[LSP (Liskov Substitution Principle)]]

## Phase 4 — Turn notes into skill
- Pick one topic and write:
  - One-liner
  - A Unity example from your project/course
  - 3 pitfalls you personally hit
  - Links to prerequisites + next steps
