# Event-Driven Architecture

## One-liner
Decouple systems by emitting events and reacting to them.

## Unity patterns
- C# events / `Action`
- ScriptableObject “event channels”

## Pitfalls
- Debugging event chains can be harder; keep naming consistent and avoid hidden global event buses.
